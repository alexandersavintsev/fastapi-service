# 📰 Baseline рекомендательного сервиса (FastAPI)

Базовая версия (baseline) рекомендательного сервиса ленты постов соцсети студентов **karpov.courses**. Сервис на **FastAPI** отдаёт по HTTP данные о пользователях, постах и действиях, а также выдаёт топ-N популярных постов по числу лайков.

Это первая часть финального проекта — фундамент для будущих персонализированных рекомендаций на ML. Выдача пока одинакова для всех пользователей: она не учитывает индивидуальные предпочтения, а показывает самые популярные посты.

---

## 🧩 Из чего состоит проект

| Файл | Назначение |
|---|---|
| `models.py` | Датаклассы `User`, `Post`, `Feed` — структура таблиц БД в виде объектов Python |
| `schema.py` | Pydantic-модели `UserGet`, `PostGet`, `FeedGet` — валидация и сериализация ответов API |
| `database.py` | Подключение к PostgreSQL через `psycopg2` |
| `helpers.py` | Функции загрузки данных: `get_user`, `get_post`, `get_feed`, `get_recommended_feed` |
| `app.py` | FastAPI-приложение с эндпоинтами |

---

## 📊 Данные

Три таблицы в схеме `public` учебной базы PostgreSQL:

| Таблица | Содержание |
|---|---|
| `public.user` | Пользователи: пол, возраст, страна, город, эксп. группа, ОС, источник трафика |
| `public.post` | Посты: текст и тема (`topic` может быть `NULL`) |
| `public.feed_action` | Действия: `view` / `like`, пользователь, пост и время |

---

## 🔌 Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/user/{id}` | Данные пользователя (404, если не найден) |
| GET | `/post/{id}` | Данные поста (404, если не найден) |
| GET | `/user/{id}/feed?limit=N` | Действия пользователя (свежие первыми) |
| GET | `/post/{id}/feed?limit=N` | Действия по посту (свежие первыми) |
| GET | `/post/recommendations/?id=..&limit=N` | Топ-N постов по числу лайков (baseline) |

## 🚀 Запуск

```bash
# 1. Клонировать и перейти в папку
git clone https://github.com/alexandersavintsev/recsys-baseline-service.git
cd recsys-baseline-service

# 2. Виртуальное окружение (Python 3.12) и зависимости
python3.12 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Запустить сервис
uvicorn app:app --reload
```

Swagger-документация — `http://127.0.0.1:8000/docs`.

### Пример запроса

```python
import requests

r = requests.get(
    "http://127.0.0.1:8000/post/recommendations/",
    params={"id": 200, "limit": 5},
)
print(r.json())
```

Ответ — список постов: `[{"id": ..., "text": ..., "topic": ...}, ...]`.

## 🔐 Подключение к базе

Параметры подключения читаются из переменных окружения (`PG_HOST`, `PG_PORT`, `PG_DATABASE`, `PG_USER`, `PG_PASSWORD`). Если они не заданы — используется публичный read-only доступ к учебной базе Karpov Courses (опубликован в задании курса; разрешено только чтение).

> В реальном проекте параметры подключения и секреты выносят в переменные окружения и не коммитят в репозиторий.
